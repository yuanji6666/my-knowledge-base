
| 符号   | 含义                                  | 后一条何时执行       |
| ---- | ----------------------------------- | ------------- |
| &&   | 与                                   | 前一条**成功**才执行  |
| \|\| | 或                                   | 前一条**失败**才执行  |
| ;    | 顺序                                  | **总是**执行,不看成败 |
| \|   | 管道:前一条的 **stdout** → 后一条的 **stdin** |               |

**管道的限制**

- 只有**读写标准流**的命令能进管道(grep、sort、awk、wc...)
- **靠参数/交互**的命令进不了(checkout、mkdir、rm、vim...)
- 桥接方法:`xargs`(stdout 转参数)、`$(...)`(输出塞进参数位)

**适用范围**

- 以上是 **POSIX shell 通用规则**,mac / Linux / WSL 都一样
- 因系统而异的只是**默认 shell**(mac 多为 zsh,Linux 多为 bash)和**个别命令参数**(如 `sed -i`)
