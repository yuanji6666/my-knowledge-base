# 问题

因为当前 gateway 方案只解决了**首次加载**，没有解决 React Router 的后续跳转。

具体流程：

1. `/test/routines` 首次加载时，boot 临时隐藏 `/test`，Router 看到 `/routines`
2. Paperclip 将无公司前缀的 `/routines` 重定向到 `/CMP/routines`
3. boot 拦截 `history.replaceState`，为了保留测试入口又写成 `/test/CMP/routines`
4. React Router 随即读取真实地址，把第一段 `test` 解析为 `:companyPrefix`
5. 最终报 `No company matches prefix "TEST"`

问题就在 `boot.js` 第 141–143 行：导航时把 `/test` 写回得太早。

本质上，gateway 同时要求：
- 浏览器真实路径必须带 `/test`，才能命中测试环境
- React Router 读取的路径不能带 `/test`

但 BrowserRouter 没配置 `basename`，两者无法通过外部脚本稳定兼容。当前 gateway hack 会在跳转、重定向、前进后退等场景反复出现 `TEST`。

可靠方案是二选一：

- 给 Paperclip 的 `BrowserRouter` 配置 `basename="/test"`（源码级正确方案）
- 测试环境使用独立域名，并挂在根路径 `/`，避免 `/test` 子路径

这次不是缓存或 Traefik 优先级问题。
