# submodule

本质上超级仓里存储的就是一个子仓库的目标CommitID

clone时看到它，翻.gitmodules，找到仓库链接

.gitmodules里的branch = master并不是实时强绑定的

```shell
git submodule update --remote #找远程master，commitID更新
git submodule update#让submodule指向本地上一次commit保存的当前submodule commitID
```

超级仓里的子模块处于“HEAD detached”状态，HEAD指向某个具体的commitID，而不是某个分支名，所以为子模块做贡献时要先checkout

如果在这种模式下commit了，一旦签出，将没有任何分支指向他们，虽然能通过commitID找回来，但是非常不安全，一段时间后会被git gc回收
