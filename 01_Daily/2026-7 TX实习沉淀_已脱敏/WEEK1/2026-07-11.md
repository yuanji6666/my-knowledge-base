# submodule

本质上就是一个子仓库的目标CommitID

clone时看到它，翻.gitmodules，找到仓库链接

.gitmodules里的branch = master并不是实时强绑定的

```shell
git submodule update --remote #找远程master，commitID更新
git submodule update          #本地上一次commit保存的当前submodule commitID
```
