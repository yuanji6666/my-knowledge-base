# AI产线上手

要学的东西：
1. **TypeScript / Node.js**：用 pnpm monorepo 管理多包，后端 Express + ORM，前端 React 19 + Vite + Tailwind。
2. **Python 3.11+**：用 uv 管理依赖，FastAPI + Pydantic 写异步服务，ruff/mypy/pytest 保证质量。
3. **AI Agent / LLM 编排**：理解多 Agent 协作、任务调度与治理，以及 MCP 工具调用协议。
4. **云原生基础设施**：Nomad 调度 + Consul 服务发现 + Vault 密钥管理（HCL 配置）+ Docker 容器化。
5. **RAG 知识检索**：LlamaIndex 框架下融合向量检索、关键词（BM25）与知识图谱（GraphRAG）三路召回。
6. **Git 高级用法**：熟练使用 submodule 组织多仓超级仓，以及 worktree 做执行隔离。
7. **软件研发流水线（DevOps/CI）**：理解「需求 → 代码 → 编译 → 门禁 → 测试 → 发布」的全链路分工。
8. **端到端测试自动化**：用声明式 YAML 描述预期结果，驱动真机/浏览器自动化与断言。
9. **业务领域知识**：读懂目标业务的领域模型、代码地图与内部平台生态。
10. **网络协议与序列化**：掌握 Protobuf/gRPC、HTTP/WebSocket 通信与 JWT 鉴权。
